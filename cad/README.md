# Native Fusion 360 model

`2602e-worlds-robot.f3z` is the original Fusion 360 assembly supplied for Team 2602E's High Stakes robot, including the embedded linked CAD components. It is **not** a mesh-only render. Open it in Autodesk Fusion.

**Git LFS:** This archive is larger than GitHub's standard Git file limit and is tracked by Git LFS through the repository's `.gitattributes` file. After cloning the repo, run `git lfs pull` to obtain the CAD bytes.

The CAD model documents a worlds-era design; the August–October 2024 notebook photos illustrate earlier iterations and should not be mistaken for the final CAD revision.
