# Engineering documentation

`2602e-high-stakes-engineering-notebook.pdf` contains the complete original 371-page team engineering notebook. It covers game analysis, mechanical mechanisms, initial and rebuilt drivetrain designs, autonomous-motion concepts, programming investigations, experimental tradeoffs, and tournament retrospectives.

Selected page reproductions appear under `media/engineering-notebook/`. These are excerpted from the supplied original notebook for convenient README display; the PDF remains the authoritative primary artifact.

Not every mechanism documented in the chronological notebook was installed on the later worlds-era robot. The notebook records designs and alternatives over time.
